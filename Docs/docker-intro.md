# Docker & Container Basics

## What is a Container?

A container is a lightweight environment that packages an application and its dependencies together.

---

## What is Docker?

Docker is a platform used to build, run, and manage containers.

---

## Why Containers?

- Lightweight compared to virtual machines  
- Faster startup  
- Consistent environments  
- Easy to deploy  

---

## Basic Docker Commands

Check version:
docker --version  

Run a container:
docker run hello-world  

List containers:
docker ps  

List images:
docker images  

---

## Containers vs Virtual Machines

- VM → Full OS, heavy  
- Container → Shares OS kernel, lightweight  

---

## Microservices (Introduction)

Microservices architecture breaks an application into smaller independent services.

Each service:
- Runs independently  
- Can be deployed separately  

---

## Real-World Use

- Application deployment  
- CI/CD pipelines
