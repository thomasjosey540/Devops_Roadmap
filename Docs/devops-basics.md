# DevOps Basics

## What is DevOps?

DevOps is a set of practices that combines software development and IT operations to improve collaboration, automation, and delivery speed.

---

## Goals

- Faster and reliable deployments
- Automation of workflows
- Continuous integration and delivery

---

## CI/CD

### Continuous Integration (CI)
Frequent code integration with automated testing.

### Continuous Delivery / Deployment (CD)
Automated release of applications to production or staging environments.

---

## DevOps Lifecycle

Plan → Develop → Build → Test → Release → Deploy → Operate → Monitor
