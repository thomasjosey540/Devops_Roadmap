# Environment Setup

## Package Management (Windows)

Chocolatey is used to install software via command line.

Example:
choco install git

---

## Operating Systems

- Ubuntu (commonly used in DevOps)
- CentOS / RHEL (enterprise environments)

## Cloud Basics

Amazon Web Services (AWS) provides cloud infrastructure.

### Core Services:
- EC2 → Virtual machines
- S3 → Storage
- IAM → Access control
- VPC → Networking
