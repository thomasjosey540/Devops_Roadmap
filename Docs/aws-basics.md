# AWS Basics

## Cloud Computing

Cloud computing provides on-demand access to computing resources over the internet.

Benefits:
- Scalability
- Pay-as-you-go
- High availability

---

## EC2 (Elastic Compute Cloud)

- Virtual servers in the cloud  
- Used to run applications  

---

## AWS CLI

Command-line tool to interact with AWS services.

Example:
aws ec2 describe-instances

---

## AWS Systems Manager (SSM)

- Manage EC2 instances  
- Run commands remotely  
- No SSH required  

---

## CloudShell

- Browser-based terminal for AWS  
- Pre-configured with AWS CLI  

---

## EBS (Elastic Block Store)

- Storage for EC2 instances  
- Persistent disk storage  

---

## ELB (Elastic Load Balancer)

- Distributes traffic across servers  
- Improves availability  

---

## CloudWatch

- Monitoring service  
- Tracks logs and metrics  

---

## EFS (Elastic File System)

- Shared file storage  
- Used across multiple EC2 instances  

---

## Auto Scaling

- Automatically adjusts number of EC2 instances  
- Handles load dynamically  

---

## S3 (Simple Storage Service)

- Object storage service  
- Used for backups, static files  

---

## RDS (Relational Database Service)

- Managed database service  
- Supports MySQL, PostgreSQL, etc.  

---

## Real-World Use

- Deploy applications on EC2  
- Store data in S3  
- Monitor systems using CloudWatch  
- Scale applications automatically  

---
