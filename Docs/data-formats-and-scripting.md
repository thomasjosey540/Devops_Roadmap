# Data Formats & Basic Scripting

## Variables

Variables store data values.

Example (Python):
x = 10
name = "devops"

---

## Python Data Structures

### List
my_list = [1, 2, 3]

### Dictionary
my_dict = {
  "name": "web-server",
  "port": 80
}

### Tuple
my_tuple = (1, 2, 3)

---

## JSON

JSON (JavaScript Object Notation) is used for data exchange.

Example:

{
  "name": "web-server",
  "port": 80,
  "status": "running"
}

---

## YAML

YAML is used for configuration in DevOps tools.

Example:

name: web-server
port: 80
status: running

---

## JSON vs YAML

- JSON uses {}
- YAML uses indentation
- YAML is more readable

---

## Real-World Use

- JSON → APIs and configuration
- YAML → Docker Compose, Kubernetes, CI/CD pipelines

---

## Key Learning

- Variables store values
- Python helps with automation
- JSON and YAML are essential for DevOps configurations
