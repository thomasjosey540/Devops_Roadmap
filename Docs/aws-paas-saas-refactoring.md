# AWS Refactoring – PaaS & SaaS Architecture

## Overview

Re-architected a multi-tier web application using AWS managed services to improve scalability, availability, and maintainability.

---

## Services Used

### Compute & Deployment
- AWS Elastic Beanstalk
- EC2

### Database
- Amazon RDS

### Caching
- Amazon ElastiCache

### Messaging
- Amazon MQ

### Networking & Delivery
- CloudFront
- Route 53
- Load Balancer

---

## Key Concepts Learned

- Refactoring monolithic deployments
- Managed cloud services (PaaS)
- Application deployment using Elastic Beanstalk
- Database initialization
- Artifact build and deployment
- CDN integration using CloudFront
- Scaling and high availability concepts

---

## Workflow

1. Build application artifact
2. Configure managed AWS services
3. Deploy application using Elastic Beanstalk
4. Connect application with:
   - RDS
   - ElastiCache
   - Amazon MQ
5. Configure CloudFront for content delivery

---

## Outcome

- Understood cloud-native architecture concepts
- Learned managed service integration
- Improved understanding of scalable deployments
